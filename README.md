# Certific Hub — atualizações

Este repositório guarda **somente os instaladores** do Certific Hub (Certific Digital) e as novidades de cada versão.
O próprio programa consulta este endereço para se atualizar sozinho.

- **Releases `v…`**: cada versão publicada, com o instalador `CertificHub-<versão>-setup-x64.exe`.
- **Release `canais`**: arquivos `estavel.yml`, `beta.yml` e `piloto.yml`, que dizem qual é a versão mais nova de cada canal.

Não apague a release `canais`: sem ela, os programas instalados não encontram as atualizações.

Suporte: Certific Digital — Crato/CE.
